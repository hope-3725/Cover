# Cover

Уеб приложение за печат на етикети по макети — вътрешен инструмент за служителите
на печатницата. Реализирани функции:

- **Управление на макети за етикети** (създаване, преглед, редактиране) —
  `specs/001-label-layout-management/`
- **Печат на A4** — пълна поръчка или избран диапазон от листове, с история на
  печата за всеки макет — `specs/002-print-layout-a4/`

JSON експорт/импорт на макети предстои като отделна функция.

Виж `Cover.md` за пълното задание и съответната `specs/.../` папка за
спецификацията, плана и задачите на всяка функция.

## Инсталация

Изисква Python 3.12+.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py migrate
```

## Стартиране локално

```powershell
python manage.py runserver
```

Приложението ще е достъпно на `http://127.0.0.1:8000/layouts/`.

## Тестове

```powershell
python manage.py test
```

## Стъпка по стъпка проверка на функциите

- `specs/001-label-layout-management/quickstart.md` — създаване, преглед/избор,
  редактиране на макет.
- `specs/002-print-layout-a4/quickstart.md` — печат на пълна поръчка, печат на
  диапазон от листове, история на печата.
